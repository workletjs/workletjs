# Landing page

Mode: Persuade. Audience: Angular developers building their first OpenLayers map. Primary task:
install the library and follow First Map. Evidence: a working map beside its Angular markup,
secondary entry point components, documented View models, and real npm/GitHub links. Scope: only
this directory; Header, Footer, routes and global styles remain untouched. User choice: prioritize
quick setup, map demonstration, and the first map. Use ng-doc.com as the layout and clarity
reference. Keep the site's English documentation language and theme behavior. Build path: code.

## Direction contract

installation to the first map; capability claims are backed by documentation links. OWN-WORLD:
Existing Nunito Sans typography, a clear blue primary color, neutral paper and quiet rules, a deep
blue code dock, no decorative gradients or card grid. Inherit the site theme. STORY: Recognize an
Angular wrapper for OpenLayers, change the live map and see the template update, copy the complete
install command, then open First Map or browse a relevant component. FIRST VIEWPORT: A large
two-line heading and compact installation controls at left; an equally prominent real map with three
location presets and readable syntax at right. Mobile stacks copy above the map; navigation belongs
to the unchanged app shell. FORM: ng-doc-inspired developer documentation landing, pinned by the
user's reference and quick-start choice. Concept seed 215ee256 does not override the pinned
reference. The signature interaction is synchronized map and template state. Motion is direct map
state changes, without entrance effects; respect reduced motion for control transitions. FINISH:
unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict,
