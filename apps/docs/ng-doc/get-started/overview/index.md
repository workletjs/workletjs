`@workletjs/ngx-openlayers` exposes OpenLayers maps, views, layers, sources, controls, interactions,
and related objects as Angular components and directives. Compose them in templates, bind supported
properties to application state, and access the underlying OpenLayers instances when needed.

The library manages registration between nested components and their hosts. Runtime updates depend
on the individual input; some options are read only when the OpenLayers instance is created.
