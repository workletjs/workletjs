Interaction component that allows the user to rotate the map by clicking and dragging on the map, normally combined with a [condition](https://openlayers.org/en/latest/apidoc/module-ol_events_condition.html) that limits it to when the `alt` and `shift` keys are held down.

> **Warning**
> This interaction is only supported for mouse devices.

> **Note**
> This interaction is included in the maps by default.
