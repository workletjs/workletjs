A component wrapped with [Feature](https://openlayers.org/en/latest/apidoc/module-ol_Feature-Feature.html) that is a vector object for geographic features with a geometry and other attribute properties, similar to the features in vector file formats like GeoJSON.

Typically, a feature component requires a single child `Geometry` component. At the same time, use a [Style](components/style/style) component to define the styling for `Geometry`.
