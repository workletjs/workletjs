# 03：可路由地图示例

Status: open

Type: task

Labels: ready-for-agent

Blocked by: 02

## What to build

在用户开启示例时生成基础地图页面，并安全接入已有 standalone 应用的懒加载路由；共享生成规则供地图应用模板复用。

## Acceptance criteria

- [ ] 默认组件名为 `map-example`、路由为
      `map`，可独立自定义；仅接受单段小写 kebab-case，拒绝嵌套路径、参数、通配符、查询字符串和路径穿越。
- [ ] 示例通过公开 secondary entry
      points 导入地图、视图、瓦片图层和 OSM 数据源组件，不引入额外 UI 框架或 bootstrap provider。
- [ ] 地图初始中心为 `[0,0]`、缩放为 `2`、高度为 `400px`，支持键盘聚焦。
- [ ] 通过实际 bootstrap 和应用配置引用定位路由，不硬编码现有应用文件名；用 TypeScript
      AST 分析路由，用 Angular 模板解析器检查根组件主出口。
- [ ] 支持内联路由数组、同文件变量及直接相对导入的静态数组，支持标准根组件内联及外部模板。
- [ ] 缺少 Router、主出口、非 standalone 或不能安全分析的配置在写入前报错，说明原因与手动接入方式，不自动修改根模板或补建 Router。
- [ ] 动态配置、展开表达式和路径别名等超出支持范围的结构明确失败，不通过字符串猜测修改。
- [ ] 新增路由为懒加载且插入根数组首位，保留其他路由的相对顺序；检查根级及静态空路径分组下的同路径冲突。
- [ ] 写入前检查全部目标文件、路由和引用；不覆盖同名业务文件，不替换首页或已有页面。
- [ ] 已有同一路由、相同组件引用和完整对应文件时重复执行保持原样并保留用户修改；其他冲突或不完整状态明确失败。
- [ ] 通过公开 collection 测试自定义参数、静态配置形式、优先匹配、出口条件、文件冲突、重复执行和失败无局部写入。
- [ ] 生成的单元测试采用浅渲染验证模板，避免依赖真实瓦片请求及 jsdom 中的 OpenLayers 浏览器初始化。

## Comments
